**App name (30):** Americano Padel
**Short description (80):** Run Americano & Mexicano padel tournaments. Live scores, no sign-up.

**Full description (4000):**
Organise a padel tournament in under a minute. Americano Padel generates the rounds, tracks every score and keeps a live leaderboard, so you can spend your time on court.

FORMATS
• Americano – partners rotate every round on a fixed schedule, so everyone plays with and against everyone.
• Mexicano – each round is seeded from the live standings (1+4 vs 2+3 on every court) to keep matches competitive.

FEATURES
• 4–20 players and 1–4 courts, with fair rest rotation
• Big, easy score fields built for using courtside
• Live standings that update as scores come in
• Share a link so players can follow along, no account needed
• Share an admin code so co-organisers can enter scores too
• Dark mode that follows your device
• Works offline in local-only mode

No ads. No sign-up. Tournaments are removed 7 days after the last update.
